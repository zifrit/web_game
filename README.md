# Browser Async RPG — MVP Specification v0.1

## Назначение документа

Этот набор документов описывает MVP браузерной асинхронной RPG: один герой, походы в данжи по таймеру, лут, экипировка, прочность предметов, ремонт, прогрессия уровня и базовая админка через Django Admin.

## Ключевая концепция

Игра представляет собой браузерную idle/async RPG, где игрок создаёт героя, отправляет его в локации/данжи, ждёт завершения похода, получает опыт, валюту и шанс предмета, улучшает экипировку и открывает более сложный контент.

Это не полноценная MMO в реальном времени. MVP фокусируется на одиночном герое и асинхронном игровом цикле.

## Core Loop

```text
Регистрация
↓
Создание героя
↓
Выбор стартового данжа
↓
Запуск похода
↓
Ожидание завершения
↓
Забрать награду
↓
Получить опыт / валюту / предмет
↓
Экипировать / починить / заменить предметы
↓
Повторить цикл с более сложной локацией
```

## Главные MVP-ограничения

- Один аккаунт имеет одного героя.
- Один герой может быть только в одном активном походе.
- Нет энергии/стамины.
- Нет PvP.
- Нет крафта.
- Нет рынка.
- Нет кланов.
- Нет отряда из нескольких героев.
- Нет real-time боя.
- Бой/успех похода рассчитывается автоматически сервером.
